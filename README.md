# Lattice — Engine Design & Documentation

This repository holds the design of **Lattice**, a rendering/game engine
built in public as a learning challenge.

> **Note:** The design documents (vision, ADRs) are written in **French**,
> the author's working language. This README is in English so the project
> stays approachable to everyone.

- **Engine code** lives in a separate repository: [Lattice-Engine/engine](…)
- **Vision**: see [VISION.md](VISION.md)
- **Module map**: see [modules/](modules/README.md)
- **Architecture Decision Records (ADR)**: see [adr/](adr/README.md)

This documentation is a living document. The vision is stable; decisions
accumulate as ADRs over time and never rewrite the past.
